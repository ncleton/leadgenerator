# NAF et effectifs

Use NAF Rev. 2 subclass codes in the API form `62.01Z`. Never invent a code. Check
the official NAF label when confidence is low. Common examples are only routing
hints: `62.01Z` programming, `62.02A` IT systems consulting, `69.20Z` accounting,
`70.22Z` business consulting, `73.11Z` advertising agencies, `85.59A` adult
continuing education, and `85.59B` other education.

The register publishes employee bands, not exact counts:

| Code | Published band |
| --- | --- |
| 00 | 0 |
| 01 | 1–2 |
| 02 | 3–5 |
| 03 | 6–9 |
| 11 | 10–19 |
| 12 | 20–49 |
| 21 | 50–99 |
| 22 | 100–199 |
| 31 | 200–249 |
| 32 | 250–499 |
| 41 | 500–999 |
| 42 | 1,000–1,999 |
| 51 | 2,000–4,999 |
| 52 | 5,000–9,999 |
| 53 | 10,000+ |

For “at least 300,” query band 32 and above, disclose that 250–299 are included,
and verify boundary candidates with a dated second source. Querying only band 41
and above would wrongly exclude companies with 300–499 employees.
