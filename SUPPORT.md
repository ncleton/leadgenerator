# Support

Use GitHub Issues for installation problems, reproducible defects, and feature
requests. Include the operating system, Python and `uv` versions, the plugin
version, the command that failed, and redacted logs.

Never include credentials, personal profiles, customer data, browser sessions,
or lead exports. Security vulnerabilities belong in a private security report as
described in `SECURITY.md`.

Support is best effort and maintained by the repository owner. Questions about
third-party services should also be checked against that provider's documentation.
