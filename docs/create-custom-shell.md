# Create an autonomous UI shell

Use `ui-bundle` only when native configuration and declarative panels cannot meet
the interaction. The extension folder contains `plugin.yaml`, a JSON Schema
configuration file, and standalone HTML for both `explorer` and `workspace`.
Every surface has a versioned `ui://` URI, title, description, and explicit CSP
domains.

The iframe reads structured tool results and sends conversational intent through
the MCP Apps bridge. It receives no database connection or integration token and
must not implement business authorization. Unknown observation kinds require a
generic representation. Paid enrichment and CRM actions continue through server
tools and kernel approval.

Install the bundle privately, preview `replace_shell`, show the complete ownership
warning, obtain explicit acceptance, apply with
`confirm_custom_ui_ownership=true`, restart MCP, and diagnose. A changed bundle
hash or unsupported SDK quarantines the shell. Text mode remains available and
the native shell is restored only by explicit request.
